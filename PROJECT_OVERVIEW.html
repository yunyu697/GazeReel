阶段二 V1 新增能力（PRD 第 10 章）

PRD 条目落地方式
DLNA 与 WebDAV（FR-09）LanHttpClient 自实现 HTTP/1.1（Android 的 HttpURLConnection 不接受 PROPFIND 非标准方法），支持 Basic 认证、chunked、重定向；WebDavScanner 解析 207 Multi-Status，HttpDirectoryScanner 解析 autoindex，DlnaScanner 做 SSDP M-SEARCH + ContentDirectory SOAP Browse，DLNA 的 res URL 直接复用 HTTP Range 播放链路
海报与进度（FR-10）优先同名 jpg/png/webp，失败生成带标题的文字封面；结果写应用私有缓存（上限 200 张）并用 LruCache 供 GL 线程读；片库主卡片显示「上次看到 mm:ss」，进度由 Room Flow 实时推送
IPD / 亮度 / 字幕 / 锁定视角（FR-12）亮度经 uBrightness 只调视频层；SDK 的 eyeFromHeadMatrix 之上叠加用户相对 62mm 的 IPD 微调；两个 HeadsetProvider 都实现 setViewLocked 冻结头追；SRT/VTT 经同一 DataSource 读取并画在控制台上方，控制台淡出后字幕仍可读
格式识别与记忆、头部手势（TC-03 / TC-05）阶段一已具备，本阶段补齐设置浮层的「重置正前方」「锁定视角」「字幕」入口，并将设置面板重排为两行三列
戴镜前配置下拉从 5 项扩为 6 项：SMB / WebDAV / FTP(阶段三) / DLNA / 本地 / HTTP；按类型给出不同地址示例，扫描失败保留配置并提示。V2.6 已重写为「只填设备地址 → 连接并选文件夹 → 可改 / 重扫 / 删」，原先手填协议头与文件夹名的口径作废，见下方 V2.6 章节
刻意没做桶形畸变：PRD 第 10 章的阶段二 V1 清单里没有这一项。正确实现需要把每眼先渲染到离屏 FBO、再用 Cardboard SDK 的 getDistortionMesh / DistortionRenderer 做后处理，并且必须按纸盒参数真机校准。在没有真机的情况下改动已验证的直出渲染管线，风险是黑屏且无法自证，因此本阶段只保留 EyeParams.distortion 预留字段，把它列为独立专项。

三条输入通道（全部来自手机本身）

凝视停留

准星射线与 2 米 UI 平面求交，1.2 秒进度环走完确认（0.6–2.4 秒可调），触发后 900ms 冷却。进度环画在同一张纹理上，左右眼必然一致。

触发键

单击执行准星目标、无目标时播放/暂停；长按 600ms 返回；双击唤出设置。无硬件盒子时由屏幕触摸/线控注入，接 SDK 后由 viewer button 驱动。

头部手势

旋转矢量低通后检测「快速往返 + 方向反转」：摇头 15° 切片、点头 10° 播放暂停或确认格式，800ms 冷却，可单独关闭。

零交互兜底

目录内自动连播、格式按文件记住、8 秒无操作控制台淡出、任意通道活动自动恢复；戴镜后不出现键盘与多级菜单。

Cardboard SDK 是怎么装上的

官方 不发布预编译 AAR：googlevr/cardboard 的 GitHub Release 只有源码包，Google Maven 里没有对应制品。因此流程是——拉 v1.36.0 源码 → 用 NDK + CMake 构建 :sdk:assembleDebug → 取未混淆的 sdk-debug.aar 放进 app/libs/。
检查项结果
release AAR（R8 开启）只剩 10 个类，HeadTracker / LensDistortion 被裁掉，不可用
debug AAR（未混淆）78 个 Java 类，含 HeadTracker / LensDistortion / HeadTransform / QrCode / Initialize
native 库arm64-v8a + armeabi-v7a 的 libGfxPluginCardboard.so
APK 内实际产物两个 .so 均已打包；dex 中存在 CardboardHeadsetProvider 与 HeadTracker/LensDistortion 引用

构建脚本 tools/install_cardboard_sdk.sh 已把整套流程固化（含代理参数），换机器可一条命令重来。

编译与运行

  1. 命令行直接构建（已实测可用）：./gradlew clean :app:assembleDebug → 产物 app/build/outputs/apk/debug/app-debug.apk（13 MB）。
  2. 或用 Android Studio 打开 cardboard-vr-player/（JDK 17）。SDK 路径已在 local.properties 中，无需额外配置。
  3. 安装到手机：adb install -r app/build/outputs/apk/debug/app-debug.apk，需 arm64/armv7 真机（x86 模拟器无 native 库，会自动回落传感器实现）。
  4. 戴镜前配置页（V2.6）选片源类型后只填设备地址，例如 192.168.1.10 或 192.168.1.10:8080；协议头与 \ / / 由程序补齐 → 点「连接并选文件夹」→ 逐级点选看得见的文件夹 → 「就用这一层」→ 自动扫描 → 「进入 VR」。DLNA / 本地无需填地址。已添加的片库可改 / 重扫 / 删。
  5. 静态校验（无需 SDK）：python3 tools/check_structure.py。
