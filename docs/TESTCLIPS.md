# 离线测试片源（2.2.0）

真机验收（`VERIFY-2.2.0.md`）里有七项要「放一部片、看朝向对不对」，而手里没有真实片库。
这份文档解决的就是这件事：**用脚本生成六段自带方位标注的片子**，戴上就能判，
不需要猜、也不需要第二个人在旁边核对。

片源不入库（`/output/` 已在 `.gitignore` 里）。它们是可复现的派生物：生成器在版本库里，
片子随时重来。

---

## 1. 生成与装到手机

```bash
python tools/make_testclips.py                  # → ../output/testclips/（六段，约 4 MB）
python tools/make_testclips.py --preview /tmp/p # 只出一帧 PNG，先看图案对不对
python tools/make_testclips.py --only fisheye   # 只重打某一段
python tools/check_testclips.py                 # 自检：公式、锚点取色、交付规格
```

推到手机（USB）：

```bash
adb push ../output/testclips/. /sdcard/Movies/
```

或者丢进 NAS 的共享目录，用应用里的 SMB 直接打开 —— 顺带把局域网那条路也走一遍。

## 2. 颜色表（判读全靠它）

每个世界方向一个固定颜色，六段片子共用同一套：

| 方向 | 颜色 | 说明 |
|---|---|---|
| 正前 0° | 红 | 打开片子**正对着**的就该是这一块 |
| 右 90° | 绿 | 向右转头 90° 才该看到 |
| 左 90° | 蓝 | 向左转头 90° 才该看到 |
| 正后 180° | 黄 | 转头 180°；360 片里它正好压在接缝上 |
| 右 45° / 左 45° | 深绿 / 深蓝 | 斜 45° |
| 右 135° / 左 135° | 橄榄 / 紫 | 斜后 135° |
| 上方 62° | 品红 | 抬头到 62° 时正对 |
| 下方 62° | 青 | 低头到 62° 时正对 |

地平线是一条更亮的蓝灰色横线；经纬网每 15° 一条，每 45° 加粗。
画面里还有一个沿地平线上方 18° 绕圈的白点和一个 `t = x.xx s` 秒表：
**它们不动就是播放卡住了**，不是方向错了 —— 这两种故障要分开。

## 4. 判读口诀

1. **先看秒表**。不动 → 播放问题，不用往下判。
2. **再看红块在不在正中**。偏左偏右是朝向问题；上下颠倒或左右镜像，去 `ProjectionMesh` 的 v / 取眼，不要调姿态。
3. **转头 90°**。该看到绿（右）或蓝（左）。看到反的那一侧，就是水平方向整体翻了个面。
4. **球面片看接缝**。接缝两侧都该是黄且对齐；出现台阶说明 u 的环绕没接上。
5. **鱼眼片看圆**。圆扁了是宽高比补偿的问题（`aspect`），圆外有东西是 UV 越界。

失败时把「哪一段、看到什么颜色在第几格、头转了多少度」记在 `VERIFY-2.2.0.md` 的记录表里。
一句话能定位的 bug，比「鱼眼不对」这种描述省一轮真机窗口。
